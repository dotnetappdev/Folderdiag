# Quick Start Guide

Get started with FoldersDiag in 60 seconds!

## 1. Download or Build

### Option A: Download Release (Easiest)
1. Go to [Releases](https://github.com/dotnetappdev/Folderdiag/releases)
2. Download `FoldersDiag.zip`
3. Extract to any folder
4. Run `FoldersDiag.exe`

### Option B: Build from Source
```bash
git clone https://github.com/dotnetappdev/Folderdiag.git
cd Folderdiag
build.bat
```

## 2. Analyze Your First Folder

1. **Launch**: Double-click `FoldersDiag.exe`
2. **Browse**: Click "Browse" button
3. **Select**: Choose your Downloads folder
4. **Wait**: Scanning takes a few seconds
5. **Review**: See your largest files and folders!

## 3. Key Features

### 🔍 Find Space Hogs
- Largest files appear at top
- Click "Size" to sort
- See full paths

### 🎨 Toggle Theme
- Press `Ctrl+D` for dark mode
- Easy on the eyes
- Professional look

### 🔄 Refresh
- Press `F5` to re-scan
- Track changes
- After cleanup

## 4. Common Uses

### Clean Up Downloads
```
File > Browse > Select Downloads folder
Look at top items
Delete what you don't need
```

### Free Up Space
```
Browse to C:\Users\YourName
Sort by Size
Find largest folders
Investigate and clean
```

### Monitor Growth
```
Scan a folder
Note the size
Use Refresh later
Compare results
```

## 5. Pro Tips

⭐ **Start small** - Scan specific folders first
⭐ **Sort by size** - Click the Size column header
⭐ **Use dark mode** - Better for long sessions (Ctrl+D)
⭐ **Refresh often** - See changes after cleanup (F5)
⭐ **Check paths** - Path column shows where files are

## 6. Troubleshooting

| Problem | Solution |
|---------|----------|
| Slow scan | Scan smaller folders |
| Access denied | Run as Administrator |
| Won't start | Install VC++ Redistributable |
| No dark mode | Need Windows 10 1809+ |
