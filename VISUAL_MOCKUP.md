## Sample Use Cases Shown

### Use Case 1: Finding Large Folders
**Scenario**: User wants to find what's taking up space on their drive

**View**: Sorted by Size (descending)
- Videos folder: 125.4 GB (largest)
- Downloads: 85.2 GB
- Documents: 45.8 GB
- User can immediately see Videos is the largest

### Use Case 2: Analyzing Project Folders
**Scenario**: Developer wants to see which project is largest

**View**: Expanded Documents → Projects
- Projects total: 32.1 GB
- WebApp: 15.3 GB (mostly node_modules at 12.8 GB)
- MobileApp: 10.2 GB
- GameProj: 6.6 GB
- Developer can identify node_modules for cleanup

### Use Case 3: File Count Analysis
**Scenario**: User wants to find folders with many small files

**View**: Looking at Files column
- Documents: 8,934 files
- WebApp: 3,102 files (many in node_modules)
- Helps identify folders that might slow down backups
