# Screenshots

This directory contains screenshots of the FoldersDiag application.

## Required Screenshots

To complete the documentation, please add the following screenshots:

1. **light-mode-main.png** - Main application window in light mode showing:
   - Toolbar with Browse, Refresh, and Toggle Theme buttons
   - ListView with folder analysis results
   - Multiple folders with size, file count, and folder count
   - Status bar showing scan completion message

2. **dark-mode-main.png** - Main application window in dark mode showing:
   - Same layout as light mode but with dark theme
   - Demonstrates the theme toggle functionality

3. **scanning-progress.png** (Optional) - Application during folder scanning showing:
   - Status bar with current scanning path
   - ListView being populated

4. **folder-browser.png** (Optional) - Windows folder browser dialog

## How to Take Screenshots

1. Build and run FoldersDiag.exe
2. For light mode screenshot:
   - Ensure light mode is active (default)
   - Use File > Browse Folder or click Browse button
   - Select a folder with some content (e.g., your Documents folder)
   - Wait for scan to complete
   - Take screenshot of the full window (Alt+PrtScn or Snipping Tool)
   - Save as `light-mode-main.png`

3. For dark mode screenshot:
   - Click "Toggle Theme" button or press Ctrl+D
   - Take screenshot of the full window
   - Save as `dark-mode-main.png`

## Screenshot Specifications

- **Format**: PNG (preferred) or JPG
- **Quality**: High resolution (at least 1280x720)
- **Content**: Show actual application window with realistic data
- **Naming**: Use lowercase with hyphens (e.g., `light-mode-main.png`)

## Adding Screenshots

Once screenshots are captured:
